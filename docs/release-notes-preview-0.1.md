# Pets Council Desktop Preview 0.1

## What this preview proves

- Codex app-server connection, model selection, threads, streaming, approvals, interruption, and explicit resume;
- bounded multi-turn conversation timeline;
- Council reviews attached to the Codex turns they reviewed;
- native workspace session browser;
- actor-specific Shared Context Graph projections;
- living companion overlay with reduced-motion support;
- one-time product layout action.

## Known limitations

- artifacts are unsigned and not notarized;
- the workflow produces portable archives, not platform installers;
- interactive smoke testing still requires a clean machine or VM for each target;
- Codex CLI installation and authentication are external prerequisites;
- session aliases are local workspace metadata and do not rename server threads;
- restored Council reviews exist only for turns reviewed during the current panel lifetime;
- external Pet Pack installation is scheduled for the next product tranche.

## Privacy and control

Pets Council does not upload product analytics. Suggestion outcomes remain local and inspectable. Prompts, approvals, graph writes, session resume, session archive, and layout changes all require explicit user action.
